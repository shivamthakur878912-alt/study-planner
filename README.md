# Study Planner

A fully functional study planner web application built with HTML, Tailwind CSS, and vanilla JavaScript. Data persists in browser localStorage.

## Features

- **Dashboard** — Dynamic stats, today's schedule, weekly chart, focus timer
- **Subjects** — Add/edit/delete subjects with progress tracking
- **Study Schedule** — Interactive calendar, session management, filters
- **Goals** — Daily/weekly/subject goals with progress tracking
- **Progress & Analytics** — Study hours, streaks, subject performance charts
- **Settings** — Profile, study targets, dark mode, data export
- **Focus Timer** — Pomodoro timer with auto-session recording

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Browser localStorage for data persistence

## Deployment

This project is deployed on Vercel as a static site.
